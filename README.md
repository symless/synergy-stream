and comes with no warranty or guarantee.

## FAQ

### What's the difference between Synergy Stream and Synergy?

Synergy is a range of stable, supported commercial products, including Synergy 1 and Synergy 3. They are quality
assurance tested, have a warranty, and are maintained by a team of full-time engineers. Synergy Stream is Deskflow's
latest code under the Synergy name, with none of that: no testing beyond Deskflow's own, no warranty and no support.

### What's the difference between Synergy Stream and Deskflow?

Only the branding. Apart from its name, its icons and the names it installs under, all of the code is Deskflow's.
The binaries are named `synergy-stream`, `synergy-stream-core` and, on Windows, `synergy-stream-daemon`, and
settings are kept in a `synergy-stream` folder rather than Deskflow's.

### How do I get it?

Synergy Stream is published as source code only, with no downloads or release builds. Build it the same way as
Deskflow, following the [build guide](docs/dev/build.md). For a ready-made app, install
[Deskflow](https://github.com/deskflow/deskflow/releases) or [Synergy](https://symless.com/synergy).

### Where should I file bugs or feature requests?

For Synergy Stream, use [Deskflow issues](https://github.com/deskflow/deskflow/issues). The code is Deskflow's, and a
fix made there reaches Synergy Stream when it next pulls from Deskflow.

For Synergy products, [contact Synergy support](https://symless.com/synergy/contact) to report a bug or ask for a
feature.

### Can I contribute code to Synergy Stream?

Contribute to [Deskflow](https://github.com/deskflow/deskflow) instead. Synergy Stream carries no changes of its own
beyond its branding, so every change to the code belongs upstream.

### How do I report a security vulnerability?

Privately, never in a public issue. See the [security policy](.github/SECURITY.md).
